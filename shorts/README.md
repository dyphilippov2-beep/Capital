# Шортсы из YouTube

Даёте ссылку на YouTube-видео, а скрипт:

1. скачивает видео (yt-dlp);
2. расшифровывает речь с таймкодами слов (Whisper, локально);
3. просит Claude выбрать самые цепляющие моменты по 20–59 секунд и придумать к ним заголовки, описания и хэштеги;
4. режет клипы в вертикальном формате 1080×1920 с крупными вшитыми субтитрами (ffmpeg);
5. по желанию выкладывает их в YouTube Shorts, Telegram-канал и VK.

## Как выбираются фрагменты

Клип должен быть понятен зрителю, который не видел остального видео, поэтому выбор устроен так:

- Расшифровка разбивается на пронумерованные предложения: по знакам препинания и паузам в речи.
- Claude получает весь текст и выбирает фрагменты номерами первого и последнего предложения, а не секундами. Поэтому клип всегда начинается с начала фразы и заканчивается её концом.
- Ему задано, что начало должно вводить тему или цеплять, а не продолжать предыдущую мысль («и поэтому…», «как я говорил…»). Конец должен завершать мысль выводом, ответом или панчлайном. Если подходящих моментов мало, Claude вернёт меньше клипов, а не добавит обрывки.
- К краям клипа добавляются короткие поля тишины, чтобы первое и последнее слово не обрезались.
- В консоли для каждого клипа печатаются первые и последние слова, а в `clips.json` есть полный текст и пояснение (`why`), чем фрагмент начинается и чем заканчивается.

Ручные таймкоды (`--clips`) тоже подтягиваются к ближайшим границам предложений. Без ИИ (`--no-ai`) клипы собираются из целых предложений, но законченность мысли проверяет только Claude.

## Установка

Нужны Python 3.10+ и ffmpeg (`brew install ffmpeg`, `sudo apt install ffmpeg` или ffmpeg.org для Windows).

```bash
cd shorts
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # ключ: console.anthropic.com
```

Запускайте на своём компьютере: YouTube часто блокирует скачивание с облачных серверов.

## Использование

```bash
# 5 лучших моментов, выбранных ИИ
python shorts.py "https://www.youtube.com/watch?v=XXXXXXXXXXX"

# 8 клипов по 30–45 секунд, видео целиком на размытом фоне вместо обрезки по центру
python shorts.py URL --count 8 --min 30 --max 45 --layout blur

# свои таймкоды
python shorts.py URL --clips "1:05-1:40,12:00-12:45"

# нарезать и сразу выложить
python shorts.py URL --upload youtube,telegram,vk
```

Результат появится в `output/<id видео>/`: файлы `01_Заголовок.mp4`, … и `clips.json` с заголовками, описаниями и хэштегами (их можно скопировать при ручной выкладке).

Полезные параметры:

| Параметр | Что делает |
|---|---|
| `--layout crop` / `blur` | `crop` обрезает центр кадра (подходит для говорящей головы), `blur` вписывает весь кадр на размытом фоне |
| `--no-subs` | без субтитров |
| `--whisper medium` | более точная, но медленная расшифровка (по умолчанию `small`) |
| `--lang ru` | указать язык речи вместо автоопределения |
| `--no-ai` | без Claude: режет равными кусками |
| `--privacy public` | сразу публичная выкладка на YouTube (по умолчанию `private`, чтобы вы сначала проверили) |

Если вы сначала хотите просмотреть клипы, а выложить потом:

```bash
python publish.py output/XXXXXXXXXXX/clips.json youtube,telegram public
```

## Автопилот: популярные видео канала → шортсы по расписанию

`auto.py` сам берёт самые просматриваемые видео вашего канала, нарезает их в очередь и выкладывает клипы по одному, а не всё разом.

1. Скопируйте `.env.example` из корня репозитория в `.env` и заполните: токен бота, `ANTHROPIC_API_KEY`, `YOUTUBE_CHANNEL` (ссылка на канал или на любое его видео) и `PUBLISH_TO` (например, `telegram,youtube`).
2. Запустите `prepare_now.bat`: он нарезает 3 самых популярных видео (по 5 клипов) и показывает очередь. Готовые клипы лежат в `output\`, их можно посмотреть до публикации.
3. Запустите `schedule.bat` один раз. Он создаст в Планировщике заданий Windows три задачи: нарезка каждое воскресенье в 03:00 и публикация каждый день в 10:00 и 19:00. Время меняется в начале файла.

Что важно знать:

- Компьютер должен быть включён в это время (спящий режим задачу пропустит).
- Уже нарезанные видео и выложенные клипы запоминаются в `output\auto_state.json`, поэтому ничего не повторяется. Если площадка трижды выдала ошибку на клипе, этот клип для неё пропускается.
- Журнал всех запусков: `output\auto.log`.
- Под каждым шортсом идут описание клипа, ссылка на полное видео, общий блок из `shorts/footer.txt` (запись в секцию, телефоны, ссылки на все соцсети) и хэштеги. Строку со ссылкой на ту соцсеть, где выходит пост, скрипт убирает. В Telegram ролик выходит только с названием и ссылкой на полное видео. Чтобы поменять текст для всех будущих шортсов, отредактируйте `footer.txt`.
- YouTube выкладывает через API только приватные видео, пока ваш проект в Google Cloud не прошёл проверку (audit). До этого клипы в YouTube придётся открывать вручную.
- Ручные команды: `python auto.py status` (очередь), `python auto.py post` (выложить следующий клип сейчас), `python auto.py prepare --videos 5` (нарезать больше).

## Автозапуск на GitHub (без вашего компьютера)

Файл `.github/workflows/shorts.yml` каждый день в 05:00 и 14:00 по UTC (10:00 и 19:00 по UTC+5) выкладывает следующий клип. Когда клипы заканчиваются, он сам нарезает следующее по популярности видео канала. В облаке хранятся не видеофайлы, а таймкоды, а перед публикацией скачивается только нужный кусок. Очередь сохраняется в `shorts/state/auto_state.json` прямо в репозитории.

Расписание работает только из ветки `main`. Настройка делается один раз в репозитории: Settings → Secrets and variables → Actions.

Вкладка **Secrets**:

| Имя | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `ANTHROPIC_API_KEY` | ключ Claude для выбора фрагментов и описаний |
| `YTDLP_COOKIES` | содержимое файла cookies.txt из браузера, где вы вошли в YouTube (расширение «Get cookies.txt LOCALLY»). Без него YouTube обычно не даёт облаку скачивать видео |
| `YOUTUBE_TOKEN_JSON` | по желанию: содержимое `shorts/youtube_token.json` после первой выкладки на ПК, если нужно выкладывать и в YouTube |
| `VK_TOKEN` | по желанию, для VK |
| `RUTUBE_LOGIN`, `RUTUBE_PASSWORD` | по желанию, для Rutube: логин и пароль от Rutube. Rutube забирает ролик по ссылке, поэтому файл сначала кладётся в релиз `shorts-files` этого репозитория (репозиторий должен быть публичным) |

Вкладка **Variables**:

| Имя | Пример |
|---|---|
| `PUBLISH_TO` | `telegram` (или `telegram,youtube,vk,rutube`) |
| `YOUTUBE_CHANNEL`, `TELEGRAM_CHANNEL` | уже заданы по умолчанию для «Лаборатории хоккея ТИТАН» и @titanhockeylab |

Запустить вручную: вкладка Actions → Shorts autopilot → Run workflow. Там можно выбрать `post` (выложить клип), `transcribe` (расшифровать популярные видео), `top` (список самых популярных видео), `status` (очередь) или `prepare` (механическая нарезка без подбора). Результат виден в журнале запуска.

### Подбор моментов по смыслу

На GitHub видео не режутся механически: моменты выбираются вручную по расшифровке.

1. `transcribe` расшифровывает следующие популярные видео и сохраняет `shorts/state/transcripts/<id>.txt` (пронумерованные предложения с таймкодами).
2. По расшифровке выбираются фрагменты с понятным началом и законченной мыслью и записываются в `shorts/state/picks/<id>.json`:
   ```json
   [{"first": 12, "last": 25, "title": "Почему конёк не катит", "description": "…", "hashtags": ["техникакатания"]}]
   ```
   `first` и `last` — номера первого и последнего предложения (включительно), длина 20–59 секунд.
3. При следующем `post` эти моменты сами встают в очередь и выходят по расписанию.

YouTube не даёт серверам GitHub скачивать видео («подтвердите, что вы не бот»), поэтому расшифровка и рендер идут на домашнем ПК: `shorts\sync.bat` расшифровывает новые видео (по умолчанию 2, число можно передать параметром), рендерит подобранные моменты в `shorts/ready` и отправляет всё на GitHub. В облаке `post` выкладывает только готовые клипы из `shorts/ready` и удаляет их после публикации.

## Настройка соцсетей

**YouTube Shorts.** В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите *YouTube Data API v3*, создайте OAuth-клиент типа «Desktop app» и скачайте JSON в `shorts/client_secret.json`. При первой выкладке откроется браузер для входа в аккаунт, после чего токен сохранится в `youtube_token.json`. Вертикальное видео короче 60 секунд YouTube сам отнесёт к Shorts. Лимит API по умолчанию — около 6 загрузок в сутки.

**Telegram.** Создайте бота у @BotFather, добавьте его администратором канала.
```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...
export TELEGRAM_CHAT_ID=@my_channel
```
Боты могут отправлять файлы до 50 МБ, минутного клипа хватает с запасом.

**VK.** Нужен пользовательский токен с правами `video,wall,groups,offline` (например, через своё Standalone-приложение на dev.vk.com).
```bash
export VK_TOKEN=vk1.a....
export VK_GROUP_ID=123456789   # id сообщества без минуса; не задан — на вашу страницу
```

**Instagram Reels и TikTok** не поддерживаются: их API разрешают публикацию только приложениям, прошедшим проверку (Meta Business / TikTok for Developers). Выкладывайте вручную готовые файлы из `output/`, взяв подписи из `clips.json`, или используйте сервис отложенного постинга, например Buffer, Later или SMMplanner.

## Важно

Нарезайте только свои видео или те, на которые у вас есть права. Перепубликация чужого контента нарушает правила площадок и может привести к страйкам.
